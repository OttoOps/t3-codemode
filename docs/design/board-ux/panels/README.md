# Panel layout mockups

The mockups filed with [issue #93](https://github.com/OttoOps/t3-codemode/issues/93),
captured from the first candidate against the live replay
([`../live/`](../live/README.md)) at 1920x1080. The judged build's stills are
in [`../judging/layout-1/stills/`](../judging/layout-1/stills/).

| File | What it shows |
| --- | --- |

| [`2-needs-you-in-middle.webp`](2-needs-you-in-middle.webp) | Needs you moved into the middle column, New issues collapsed, the split resized. |

| [`4-rearranged-dark.webp`](4-rearranged-dark.webp) | A rearranged layout in the dark theme. |
